## Исследование

в репозитории представлены ветки, в которых проводилось исследование и тестирование различных методов:
- research/tabular_q_learning - исследование табличного метода q-обучения для среды FrozenLake;
- research/state_dqn - исследование метода DQN для дискретных действий;
- research/state_text_transformer - первая попытка создания объяснителя, в основе классическая архитектура трансформера, с видоиpменённым первым энкодер-блоком;
- research/a3c - исслеование метода A3C;
- research/ddpg - исследование метода DDPG для сред с непрерывным пространством действий;
- research/ppo - исследование метода PPO.
