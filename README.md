Алгоритм основан на коде, предложенном в книге Maxim Lapan Deep Reinforcement Learning Hands-On

Версия Python 3.11.9

Релизован алгоритм Asynchronous Advantage Actor-Critic:
- использование advantage в вычислении градиента;
- использование распараллеливания для расчёта градиента в разных эккземплярах одной среды:каждый воркер играет в своей среед и вычисляет градиент, затем мастер-процесс собираем градиенты и обновляется веса сети;
- используется одна сеть с одщим началом и двумя головами: actor и critic.

В качестве объяснителя реализована классическая архитектура трансформера, с изменённым первых энкодер блоком. Новый энкодер блок принимает на вход две последовательности и обрабатывает их в один вектор скрытого состояния.

Также реализовано версионирование моделей (папки agent_models и explainer_models текущего репозитория) с автоинкрементом номера модели. В каждой версии содержится два файла: 
- weights.dat - веса модели
- info.yml - информация по процессу обучения (количество итераций, гиперпараметры)

Пример запуска:

```
python train_agent.py --model-dir agent_models --verbose
```
```
python train_transformer.py --dataset-dir dataset/data.json --model-dir explainer_models
```
```
python demo.py --agent-dir agent_models --explainer-dir explainer_models --video videos
```
